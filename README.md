# **Summer Research: Tello Drone Project**

**Overview**: Tello Drone Project was a summer research opportunity where I learned how to operate a drone through hand-gesture recognition. The initial stages consisted of importing basic block coding into the drone to perform short circuits. Once I felt comfortable with basic block coding logic, I began to implement python algorithms so the drone may perform additional circuits, while involving more components (i.e., recording footage, taking pictures, etc.). The final stage of this project required shifting to the Linux operating system and applying pre-trained machine-learning models and code from Nikita Kiselov (https://github.com/kinivi) for hand-gesture operation of the drone. 

Project Content:
* Personal python algorithms for systematic testing of drone
* Python algorithms inspired by or obtained from Nikita Kiselov's project
